# 换电池后耗电快排查

- **日期**：2026-11-22（时间均写本机时间 UTC+8）
- **环境**：MateBook 14 2024（`FLMH-XX`），2026-11-08 更换新电池（`HB5489P9EGW-31A`，NVT）
- **依据**：`powercfg /batteryreport /xml`（11-22 09:25 生成，未存档）、`battery-charge/var/history.log`（11-11 起）、系统日志 Kernel-Power / Kernel-General / User32 1074
- **问题现象**：11-08 更换新电池后，主观感觉耗电速度明显变快。

---

## 一、 排查结论

**电池硬件正常，平均放电功率并未高于换电池之前。** 主观感觉“变快”由以下三个因素叠加造成：

1. **80% 充电上限导致可用绝对容量与旧电池接近**：新电池满充 70.1 Wh，限制 80% 上限后的实际可用容量为 56 Wh；换电池前旧电池老化后的满充容量为 53–56 Wh。两者单次满电可用能量相近，未体现出新电池多出的约三成续航。
2. **11-20 夜间关机后意外重启并持续亮机放空**：11-20 23:38 从开始菜单执行关机（User32 1074 记录为 `power off` / `Power Action Shutdown Off`，而当晚 22:04 的正常重启记录为 `restart` / `Power Action Reboot`），但 80 秒后（23:40:14）系统冷启动（`Kernel-Boot 27` `boot type = 0x0`，且注册表 `HiberbootEnabled = 0` 已关闭快速启动）。2026-11-24 追查 `System` 日志与 `powercfg /sleepstudy /duration 7 /xml`（`OsStateId=300.0`）证实：系统并未停在未登录界面，而是在 23:40:23 触发了 `Winlogon 7001`（自动登录进桌面），随后进入长达 31,088 秒（8.63 小时）的 `Active` 会话，屏幕在 **100% 亮度下持续亮屏 31,087 秒**，全程未进入现代待机（无 `Kernel-Power 506`），放空 41,966 mWh（59% → 3%，平均功耗 4.86 W），至 11-21 08:18 触发电量危急自动休眠。该会话 SRUM 功耗前几项为 `explorer.exe`（`Disp=2642`）、`D:\uv\python\cpython-3.14.8\python.exe`、`vmmemWSL`、`PickerHost.exe`、`Code.exe`、`powershell.exe`、`verge-mihomo.exe`、`D:\miniforge3\pythonw.exe`。注：11-08 17:08:31 关机仅 2 秒后（17:08:33）及 19:20:24 关机 101 秒后（19:22:05）也曾冷启动，OS 侧均无唤醒源记录，触发点在断电后的固件/EC/硬件侧。
3. **11-21 至 11-22 期间后台高负载导致电池平均功耗升至约 18 W**：
   - 11-09 至 11-20 多数日子电池平均功耗为 8–14 W；
   - 11-21 21:33–22:54 为 18.4 W，23:31–00:35 为 18.3 W，11-22 06:56–09:18 为 17.8 W（75% → 16%）。
   - 11-22 09:20 观测到后台高负载进程包括：FFmpeg 编译（十余个 `nasm` 进程，CPU 约 90%）、`mybili serve`（04:01 起运行，占约 1/3 核）、一个 3.4 GB 的 OCR 进程、Antigravity 及多个 Claude 进程（除 `mybili serve` 外，其余在 06:56–09:18 电池供电期间是否已运行未核实）。
