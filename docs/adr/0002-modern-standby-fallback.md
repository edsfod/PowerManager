# ADR-0002: 禁用电源键，用"缩短闲置超时 + 休眠兜底"控制睡眠

## 背景

需求：跑任务时关屏、合盖都不打断任务（SLP-05、SLP-07）；普通模式合盖约 1 分钟后睡眠（SLP-06）；在包里睡不下或意外唤醒时不能持续发热（SLP-10、SLP-11）。

本机实测的约束（[windows-standby-and-toast.md](../reference/windows-standby-and-toast.md)）：

- 没有 S3 睡眠，只有现代待机（S0ix）与休眠（S4）。
- 程序无法直接请求进入现代待机：`SetSuspendState(睡眠)` 与 `NtInitiatePowerAction(睡眠)` 在有 CPU 负载时直接转为休眠；模拟睡眠键无反应。唯一可控的途径是缩短闲置超时，而且只在屏幕已关闭、整机空闲时生效。
- 轻触电源键被固件过滤；把电源键设为"关闭显示器"后，按住 1–2 秒会直接进入现代待机并冻结后台。

## 决策

1. **禁用电源键**：电源键动作设为"不采取任何操作"。关屏只靠闲置超时；关机与手动睡眠通过开始菜单。
2. **合盖交给常驻程序**：Windows 合盖动作设为"不采取任何操作"。需要睡眠时，由常驻程序临时把关屏与睡眠超时缩短到数秒，等系统因闲置进入现代待机；开盖或醒来后恢复。
3. **休眠兜底**：常驻主动要求睡眠后 2 分钟仍未睡下，或合盖时意外醒来 2 分钟后仍醒着（"保持运行 + 插电"除外），调用 `SetSuspendState(Hibernate)` 强制休眠。

## 备选方案

1. **电源键设为"关闭显示器"**：按住稍久就会进入现代待机并冻结后台，做不到"只关屏、不停任务"。
2. **直接调用睡眠 API**：有负载时会变成休眠，不是睡眠；空闲时也无法稳定进入现代待机。
3. **只靠缩短超时、不做休眠兜底**：后台高负载时系统不会进入现代待机，在包里会持续高功耗发热。

## 影响

- 普通模式下后台确有高负载时，合盖 1 分钟后睡不下，约在第 3 分钟转为休眠；休眠文件约 12.6 GB 的写入只在兜底时发生。
- 合盖动作设为"不采取任何操作"后，合盖时系统不再发送"显示器已关闭"通知，外接显示器检测改用 `QueryDisplayConfig`。
