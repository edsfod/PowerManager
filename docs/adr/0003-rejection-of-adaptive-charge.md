# ADR-0003: 只用 EC `0x10` 锁定固定充电阈值，加单次临时冲高；不做自适应充电

## 背景

需求：电池不长期满充（G3、CHG-01），需要时可临时多充（CHG-02）。

本机的事实（[wmi-ec-interface.md](../reference/wmi-ec-interface.md)）：

- ACPI WMI（`OemWMIMethod`）只提供设定启充 / 停充百分比的 `0x10`（`SBTT`）接口，没有设置充电电流的接口；恒流、恒压由电池包与充电芯片在硬件层完成。
- 电池为 3 串、单串 4.48 V、约 70 Wh。
- EC 在高负载或高温时会自行把充电电流从 1984 mA 压到 448 mA，降温后放开。
- `0x12`（`SBAC`）是单次插电放开限充的"恢复充电"标志，反复写入会干扰智能保护；`0x15`（`SBCM`）单独写入无法限充到 80%。

## 决策

1. **只写 `0x10`**：日常阈值固定为 `75%–80%`，在 `PowerPolicy` 中定义，不暴露外部可编辑的配置。
2. **只提供单次临时冲高**，带自动回落（条件见 CHG-02）；不设永久 100% 开关，也不设手动恢复按钮。
3. **不干预 EC 自身的限流**：`0x12` 与 `0x15` 只读不写。

## 备选方案

1. **自适应充电算法**（按周期动态计算充电电流，含恒流 / 降流 / 恒压与温度降额）：硬件没有设置电流的接口；算法默认的电芯参数（单节 4.20 V、4.5 Ah）与本机电池不符；EC 已有热保护，无需软件重复干预。
2. **永久 100% 开关，或沿用华为电脑管家的 `0x12` / `0x15` 写法**：`0x12` 反复写入会干扰智能保护，`0x15` 单独写入不能限充；永久开关容易切高后忘记改回，导致电池长期满充。

## 影响

- 充电控制收拢为纯决策函数（何时冲高、何时回落），没有电流闭环计算。
- 重启后 EC 阈值复位为 `95–100`，必须由开机及登录前就能运行的 S4U 计划任务写回日常阈值。
